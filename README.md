# Scraper App GUI

Aplicación de escritorio hecha en Python para extraer datos de cualquier sitio web con una interfaz amigable. Ideal para usuarios no técnicos que necesitan scraping personalizado.

## Características

- Extracción con etiquetas específicas (`span`, `div`, etc.)
- Filtros por palabra clave
- Exportación a Excel, CSV o JSON
- Interfaz moderna (Tkinter + CustomTkinter)

## Cómo usar

1. Ejecuta `main.py`
2. Ingresa la URL, etiquetas, y filtro
3. Haz clic en "Extraer"
4. Exporta el archivo generado
